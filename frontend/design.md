## 1. Концепция и tone of voice

### Метафора
Сайт — это персональная операционная система мага-исследователя. Не портфолио в классическом смысле, а живой артефакт: технический гримуар, в котором фиксируется путь разработчика. Каждый раздел — глава книги. Каждый проект — заклинание в процессе создания.

### Tone of voice
- Технический, но не сухой
- Личный, но не неформальный
- Любопытный, исследовательский
- Лёгкая аниме-эстетика без китча
- Игровые отсылки как easter egg, не как основной элемент

### Целевая аудитория
Первичная — технические рекрутеры и разработчики из сферы AI, gamedev, EdTech.  
Вторичная — коллеги и сообщество, которые ценят нестандартный подход.

## 3. Типографика

### Шрифты
- **Основной шрифт:** Inter или аналог (современный, технический, высокая читаемость)
- **Моноширинный шрифт:** JetBrains Mono (для терминала, тегов, метаданных, кода)
- **Акцентный шрифт (опционально):** Можно использовать тот же Inter с увеличенным letter-spacing для заголовков

### Шкала типографики

| Элемент | Размер | Вес | Letter-spacing | Применение |
|---|---|---|---|---|
| Hero заголовок | 32–40px | 500 | -0.02em | Главный заголовок на hero-секции |
| H1 страницы | 24px | 500 | -0.01em | Заголовок статьи или страницы |
| H2 секции | 18px | 500 | 0 | Подзаголовки внутри страницы |
| H3 | 15px | 500 | 0 | Заголовки карточек, подсекции |
| Body | 15px | 400 | 0 | Основной текст статей |
| Caption | 13px | 400 | 0 | Описания карточек, мета-информация |
| Label | 11px | 500 | 0.08em | Лейблы разделов (ALL CAPS), теги |
| Mono | 12–13px | 400 | 0 | Даты, slug, технические метки, код |

### Принципы
- Вес используется только 400 и 500. Никакого 700.
- Заголовки не ALL CAPS кроме section labels (11px).
- Межстрочный интервал body-текста: 1.7.
- Максимальная ширина строки в статьях: 68ch.

## 4. Компоненты и сетка

### Сетка
- Максимальная ширина контента: 1100px
- Боковые отступы: 24px (мобиль), 48px (десктоп)
- Внутренние отступы карточек: 16px (мобиль), 20–24px (десктоп)
- Gap между карточками: 12–16px

### Карточка (Card)
**Базовое состояние:**
- Фон: `#FFFFFF`
- Граница: `0.5px solid rgba(127,119,221,0.15)`
- Скругление углов: 12px
- Паддинг: 16px 20px

**Акцентная карточка (featured):**
- Левая граница: `2px solid #7F77DD`
- Скругление: `0 12px 12px 0` (только правые углы)

**Hover-состояние:**
- Граница становится чуть ярче: `rgba(127,119,221,0.3)`
- Лёгкий подъём: `transform: translateY(-1px)`
- Переход: `transition: all 150ms ease`

### Бейдж (Badge)
- Высота: 20px
- Паддинг: 2px 8px
- Скругление: 20px (pill)
- Шрифт: 10px, weight 500
- Цвета согласно семантической палитре (секция 2)

### Тег (Tag / Sigil)
- Аналогично бейджу
- Основной вариант: фон `#EEEDFE`, текст `#3C3489`, граница `0.5px solid #AFA9EC`
- Серый вариант: фон `#F1EFE8`, текст `#5F5E5A`

### Разделитель (Divider)
Декоративный разделитель между секциями:
```

```
- Линии: `0.5px` высота, цвет `rgba(127,119,221,0.2)`
- Текст по центру: 11px, mono, `#AFA9EC`, letter-spacing 0.1em

### Статус-индикатор
- Зелёная точка: `width: 6px; height: 6px; border-radius: 50%; background: #1D9E75`
- Рядом: 12px текст, цвет `#5F5E5A`

## 5. Навигация

### Структура
Фиксированная шапка, прилипает к верху при скролле с лёгким backdrop-blur.

**Левая часть — логотип:**
```
jiene
· · · grimoire · · ·
```
- `jiene`: 15px, weight 500, цвет `#7F77DD`
- `· · · grimoire · · ·`: 9px, mono, цвет `#AFA9EC`, letter-spacing 0.15em

**Центральная часть — ссылки:**
- `chronicle` / `codex` / `laboratory` / `about`
- Размер: 13px, weight 400
- Обычный: цвет `#5F5E5A`
- Активный: цвет `#7F77DD`
- Hover: цвет `#3C3489`
- Без подчёркивания, без бордеров

**Правая часть — подсказка терминала:**
```
~ terminal
```
- 11px, mono, фон `#F1EFE8`, граница `0.5px solid rgba(127,119,221,0.2)`, скругление 4px, паддинг 2px 8px
- При hover: фон `#EEEDFE`, курсор pointer
- Кликабельна — открывает терминальный оверлей

**Параметры навигации:**
- Высота: 52px
- Фон при скролле: `rgba(255,255,255,0.85)` + `backdrop-filter: blur(12px)`
- Граница снизу: `0.5px solid rgba(127,119,221,0.12)`
- Паддинг: 0 48px (десктоп), 0 20px (мобиль)

## 8. Терминальный оверлей

### Поведение
- Открывается по нажатию `~` или `⌘K` или клику на `~ terminal` в навигации
- Закрывается по `Escape` или клику вне области
- Анимация появления: slide-down + fade, 200ms ease

### Позиционирование
- Появляется в верхней части экрана (не по центру — как в реальных терминалах)
- Ширина: 640px максимум, центрирован по горизонтали
- Отступ сверху: 80px (ниже навигации)
- Максимальная высота: 60vh, с прокруткой внутри

### Внешний вид
- Фон: `#14101F`
- Скругление: 12px
- Граница: `0.5px solid rgba(127,119,221,0.3)`
- Паддинг: 16px 20px

**Топбар терминала:**
- Три точки слева: красная `#FF6058`, жёлтая `#FFBD2E`, зелёная `#28C840` — диаметр 10px, gap 6px
- Лейбл справа от точек: `grimoire terminal — v0.1.0` — 11px, mono, цвет `#6B6585`

**Текст в терминале:**
- Основной текст: 12px, mono, line-height 1.6
- Промпт-символ `~`: цвет `#7F77DD`
- Команды: цвет `#D4CFEC`
- Вывод / описание: цвет `#6B6585`
- Выделенные значения: цвет `#AFA9EC`

## 11. Анимации

### Принципы
- Все анимации отключаются при `prefers-reduced-motion: reduce`
- Ничего не анимируется "для красоты" — только для передачи информации или обратной связи
- Никакого parallax на scroll — это тяжело и раздражает

### Список анимаций

**Появление страницы:**  
Fade-in + subtle slide-up для основного контента.  
Duration: 300ms, easing: `ease-out`.  
Задержка для последовательных элементов: +60ms каждый.

**Hover карточки:**  
`translateY(-1px)` + усиление border opacity.  
Duration: 150ms.

**Статус-точка (зелёная):**  
Мягкое пульсирование через `box-shadow`.  
```css
@keyframes pulse {
  0%, 100% { box-shadow: 0 0 0 0 rgba(29, 158, 117, 0.4); }
  50%       { box-shadow: 0 0 0 4px rgba(29, 158, 117, 0); }
}
```
Duration: 2s, infinite.

**Появление терминала:**  
`transform: translateY(-8px)` → `translateY(0)` + `opacity: 0` → `1`.  
Duration: 200ms, easing: `ease-out`.

**Курсор в терминале:**  
Мигание: `opacity: 1` → `0` → `1`.  
Duration: 1s, step-based, infinite.

**Hero заголовок (опционально):**  
Typewriter-эффект только для подзаголовка, если это не мешает воспринимать контент.  
Если реализуется — скорость: 40ms на символ.

**Декоративный divider:**  
При первом появлении в viewport: линии "вырастают" от центра к краям.  
Duration: 400ms, easing: `ease-out`.  
Trigger: Intersection Observer.

## 13. Общие правила для дизайнера

1. **Никакого gradients, drop shadows, blur на основных элементах.** Исключение — backdrop-blur на навигации при скролле.
2. **Все рамки — 0.5px.** Не 1px. Это принципиально для лёгкости.
3. **Два веса шрифта:** 400 и 500. Не 600, не 700.
4. **Фиолетовый — единственный акцентный цвет.** Нет оранжевых кнопок, нет синих ссылок.
5. **Пустое пространство — часть дизайна.** Не заполнять каждый пиксель.
6. **Тёмная тема:** инвертировать фон на `#14101F`, текст на `#D4CFEC`, акцент остаётся `#7F77DD` (он одинаково работает на светлом и тёмном).
7. **Логотип `jiene` никогда не меняет размер** — только цвет в зависимости от фона.
