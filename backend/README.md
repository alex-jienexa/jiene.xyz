### Создание ключей авторизации

Вы не можете запустить приложение без ключей авторизации в переменных окружения.
Ключи авторизации хранятся в переменных `JWT_SECRET` и `ADMIN_PASSWORD_HASH`.

Чтобы создать `JWT_SECRET`, выполните команду:
```bash
openssl rand -base64 32
```

Для создания `ADMIN_PASSWORD_HASH`, выполните команду:
```bash
go run ./cmd/hashpassword "ваш-пароль"
```

Сохраните полученные результаты в соответствующие переменные в `./env` в главной директории (не в `./backend`).
Данные действия достаточно выполнить один раз при первом запуске проекта.
