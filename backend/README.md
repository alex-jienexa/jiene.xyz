### Создание ключей авторизации

Вы не можете запустить приложение без ключей авторизации в переменных окружения.
Ключи авторизации хранятся в переменных `JWT_SECRET` и `ADMIN_PASSWORD_HASH`.

Чтобы создать `JWT_SECRET`, выполните команду:
```bash
openssl rand -base64 32
```

Сохраните полученные результаты в соответствующие переменные в `./env` в главной директории (не в `./backend`).
Данные действия достаточно выполнить один раз при первом запуске проекта.

Чтобы иметь возможность к админ-функциям приложения, нужно создать пользователя с правами админа.
Если вы запускаете приложение через docker-dev окружение, то он создаётся автоматически:
```
username: devuser
password: admin_
```

Если же вы запускаете приложение без Docker, то пользователя нужно создать вручную.
Делается это с помощью запуска CLI-утилиты в Go:
```sh
go run ./cmd/createuser -username "User" -password "..."
```
У вас уже должен быть запущен PosgreSQL сервер, чтобы успешно создать пользователя.
Информация о новом пользователе будет записана в БД и информация будет браться оттуда.
Если вы очистите базу данных (или каким-то другим образом база будет очищаться), вам необходимо будет снова создать пользователя таким же образом.
